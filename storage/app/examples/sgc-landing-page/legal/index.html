Esta central reúne os documentos de transparência, privacidade e uso do SGC — Sistema de Gestão Cooperativa. O objetivo é deixar claro como a plataforma funciona, como dados pessoais podem ser tratados e quais canais devem existir para solicitações.

Estrutura pensada para SaaS multi-organização: a qualificação jurídica pode mudar conforme o contexto. Em muitos cenários, a organização cliente atua como controladora dos dados que cadastra no seu ambiente, enquanto o responsável pelo SGC atua como operador conforme as instruções contratuais. Para dados da própria relação comercial, segurança, suporte e administração do serviço, o responsável pelo SGC pode atuar como controlador.
